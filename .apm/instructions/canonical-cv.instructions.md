# Canonical CV source files

The canonical, authoritative CV working files live at the project root:

- `cv.md` — primary CV in English.
- `cv_es.md` — primary CV in Spanish.

## Rules

- These two Markdown files are the single source of truth for the professional
  profile. Every other CV artifact (PDF, DOCX, tailored versions) is derived
  from them.
- They are language-paired: the same verified facts, roles, dates, and
  credentials must appear in both. When one is updated with new verified
  information, the other must be updated with the equivalent content in its own
  language.
- Keep structure, section order, and headings consistent between the two files.
- Never overwrite these files without understanding the current content first.
  Read before editing, and make the smallest complete set of changes.
- Do not fabricate facts. Only record verified information provided by the user
  or extracted from an authoritative source the user supplied.
