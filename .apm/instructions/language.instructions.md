# Language policy

- Always write every conversational response, explanation, progress report,
  question, and final summary in the language the user is currently writing in.
  If the user switches language mid-conversation, follow the switch.
- Produce each deliverable in the language explicitly requested by the user.
  If no language is specified for a deliverable, infer it from the target market
  or the existing document, and ask only when the choice materially changes the
  result.
- `cv.md` is written in English; `cv_es.md` is written in Spanish. Keep each file
  in its own language.
- Preserve accurate professional terminology. Do not mechanically translate
  academic degrees, job titles, or technical terms when that would misrepresent
  their meaning.
